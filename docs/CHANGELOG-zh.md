# CRASH!城市破坏者 v0.5

以 Burnout CRASH! 的路口事故玩法为参照的 3D 浏览器街机游戏。当前有**旧金山、悉尼、伦敦三座独立城市地图，共九条入场路线、23 种车型与四种玩家主动技能**。坡道、错位路口和环岛采用不同的实际道路与车流路径；每城还有自己的重点交通和现场事件。v0.4 完善真实车型图鉴、贴路破坏目标、中英切换、特殊车提示及四模式共同的披萨抽奖。**v0.5 加入波间三选一强化、开局合约、每日挑战与修饰词、连锁顿帧与分级喊话、星星解锁涂装。**

这是一版原创改编：保留冲进路口、反复爆破、控制残骸和扩大连锁的核心循环，参考经典模式与街机界面的呈现。城市布局、玩家技能、城市事件、模型和音效由本项目制作，并非原作关卡或原片的逐帧复刻。本轮变化详见 [POLISH-V4.md](POLISH-V4.md)，三城与技能说明保留在 [WORLD-TOUR-V3.md](WORLD-TOUR-V3.md)，原实况观察与来源继续保留在 [REFERENCE-STUDY.md](REFERENCE-STUDY.md)。

## 本机试玩

**最快方式**：macOS 双击 `start.command`，其他系统运行 `./start.sh`。它会自动安装依赖、构建并在浏览器打开游戏；关闭终端窗口即停止。

需要 Node.js 22 或更新版本。首次安装依赖：

```sh
npm install
npm run dev
```

开发预览：[http://127.0.0.1:5173/](http://127.0.0.1:5173/)。构建生产包后试玩：

```sh
npm run build
npm run preview
```

生产预览：[http://127.0.0.1:4173/](http://127.0.0.1:4173/)。这些地址需要对应的本地服务正在运行。

- **WASD / 方向键**：入场转向，碰撞与爆破后调整残骸移动和落点。
- **鼠标 + 单按空格**：瞄准推进方向，释放满槽 Crashbreaker；碰撞能加快回充。
- **Q**：释放当前车辆的主动技能；需要冷却结束，并有足够爆破能量。
- **Esc**：暂停；**R**：按当前配置重开。
- **1 / 2 / 3**：选择强化或合约；**4**：跳过合约。
- **Sandbox 专用**：E 开启机关慢动作，1 / 2 / 3 选择绿灯、落货、广告牌；每局三次，选择时仍计时。

## v0.5：每一局都走出不同的路

- **波间三选一强化**：Road Trip 每波结束、Pile Up 处理 15 辆后、Rush Hour 剩 60 / 30 秒时，从九种强化里随机给三张，选一张带进下一段。强化包括广域冲击、重装弹头、连锁红利、余烬引信、极速回充、技能涡轮、高价货柜、紧急路障、披萨热线。选择时现场冻结，按 1 / 2 / 3 或点击；强化由种子决定，同一挑战编号可复现。
- **开局合约**：出发前给三张合约（拆迁队、连环狂欢、特种猎手、空中飞人、技能大师、爆破组合、殉爆接力、零逃脱），可接一张或按 4 跳过。完成后一次性加 25 万到 50 万美元，并多算一颗星。「零逃脱」只在真正完成终局时结算，超时不算。
- **每日挑战**：车库右下角按日期固定城市、路线、车辆、规则和一个修饰词（油罐暴动、冰面路口、超速车流、玻璃大炮、月面重力、黄金车队）。本机记录今日最佳与连续天数；同一天的所有人拿到同一套种子。
- **爽感反馈**：Crashbreaker 引爆有 70 毫秒顿帧；连锁到 8 / 16 / 25 / 40 或一爆摧毁五辆以上时，弹出 `NICE CHAIN!` → `TOTAL CARNAGE!` 分级喊话，伴随慢动作、冲击环和专属音效。连锁旁常驻显示当前得分倍率。关闭「撞击震屏」会同时关闭顿帧与慢动作。
- **星星解锁涂装**：每局得到的星星累计进个人档案，3 / 8 / 15 / 25 / 40 / 60 星解锁六种车身涂装，只改颜色不改数值。涂装应用到车库预览和场上玩家车。
- 新增 `tests/v5-perks.test.ts`，覆盖强化抽取、合约结算、每日种子、修饰词与冻结逻辑；全套测试 **116 / 116** 通过。规则版本升为 `CRASH-05.0`，旧纪录按版本分组保留。

## v0.4 直接可见的变化

- **真实车型图鉴**：23 种车型均使用游戏模型渲染的缩略图，点击可放大查看三维实车；模型名称、颜色与实际车体对应。
- **街区更连贯**：地面、外围道路和岸线向镜头外延伸，常规视角不再露出桌面式地图板边；可破坏建筑更靠近道路，让爆破与残骸更容易接上店面、仓库等财产目标。
- **特殊车辆更容易辨认**：九类重点车有彩色地面圈和用途提示。最多同时显示六个地面圈、三个文字提示，优先突出披萨车与救护车。
- **中文 / English**：车库右上角、设置和成绩页均有切换入口。暂停中切换保留本局时间、随机种子、成绩和冷却；语言随设置保存在当前浏览器，刷新后恢复。
- **四模式都有披萨奖励**：预告、车辆到场和撞毁抽奖是三个不同阶段。中奖时轮盘与滚条展示真实奖励，并显示剩余时长；每两次中奖还能追加特殊交通。

## 三城与四辆玩家车

| 城市 | 道路与打法 | 本城事件 |
|---|---|---|
| 旧金山 金门坡道 | 真正有高度差的坡道十字路口；利用缆车大惯性，把事故推向下一股车流 | 缆车暴走 |
| 悉尼 歌剧院港湾 | 两个错位路口；利用工程皮卡的散落工具、双挂重卡的独立挂车，把两处拥堵连起来 | 货港倾落 |
| 伦敦 西敏钟楼环岛 | 车流沿环岛绕行；把双层巴士侧翻在弯道，封住黑出租的绕行空隙 | 红色封锁 |

每城有三条不同入场路线，城市选择与路线选择独立。四辆玩家车跨城共用，车型与首批配装均开放。

| 玩家车 | Q 主动技能 | 冷却 | 爆破能量消耗 |
|---|---|---:|---:|
| 小旋风 | 磁吸弹跳：先聚拢车流，再腾空落位 | 12 秒 | 15% |
| 赤线 GT | 三连穿刺：沿瞄准方向连续三次冲击 | 10 秒 | 20% |
| 野牛皮卡 | 废铁投手：向目标抛出附近最多五件残骸 | 11 秒 | 10% |
| 铁山重卡 | 重锤封街：震开车辆，横摆车身封路 | 15 秒 | 25% |

主动技能与满槽爆破共用能量。技能适合聚拢、转移或封路；连续命中新目标再补回爆破槽。23 种车型是全游戏的车型总数，其中四种可由玩家驾驶，**不是 23 辆玩家车**。

## 四种规则

三城均可选择四种规则：

| 玩法 | 主要限制 | 终局 | 适合的打法 |
|---|---|---|---|
| Road Trip / 公路之旅 | 60 辆车、三波；五辆完整逃脱失败 | 处理完车流后进入灾难；逃脱越少，终场威力越强 | 连续封路，适时放行救护车，守住出口 |
| Rush Hour / 高峰时刻 | 90 秒竞分，逃脱不扣机会 | 玩家位置发生终场大爆破并等待物理结算 | 追击高价值目标，最后停在密集车群或建筑旁 |
| Pile Up / 连环堆撞 | 30 辆车；逃脱削弱终局倍率 | 进入 Inferno，燃烧和新破坏延长连锁 | 先堆积残骸与可燃目标，再持续引燃 |
| Sandbox / 自由连锁 | 120 秒，自选爆破 / 被动配装，三次 E 机关 | 时间结束结算 | 自由组合技能、配装与机关；保留脉冲车和磁力回收车 |

**五星不是五个分数门槛**：三颗来自分数目标，一颗来自终局目标，一颗来自「建筑坍塌或收集钱袋」本地挑战。Sandbox 的终局目标是完整完成一局。v0.4 降低三种参考规则的部分分数门槛；当前金额以 [rules.ts](src/simulation/rules.ts) 为准，[POLISH-V4.md](POLISH-V4.md) 列有本轮对照表。

开局 20 辆预置车辆移到入口上游，并用四秒逐步提速，给玩家建立封锁的时间，避免入场时突然连续出现五辆逃脱。在同一套 36 局脚本样本中，达到总三星的局数由 23 增至 34，达到第三档分数目标由 10 增至 15，全五星由 8 增至 14；这些是受控脚本结果，不代表人类玩家胜率。

四模式共同的披萨奖池为好警察封路、磁吸、双倍得分、冻结交通。独立的种子洗牌袋每袋四抽各出现一次，跨袋也不会连续抽到同一奖；相同种子可复现奖励顺序。每累计两次中奖，追加运钞、冰淇淋、导弹或载车运输车之一。

交通车辆有可辨认的载荷和行为：救护车要放行，运钞车会掉钱袋，油罐车延迟爆炸，推土机会清障，披萨车、导弹车和冰淇淋车能改变现场。建筑经历完整、破损、坍塌、残墙地基阶段，碰撞体随损毁降低；城市事件通过标记区域内的真实碰撞和玩家爆破充能，每局各触发一次。

本地五星挑战、按城市和配置区分的纪录、同机轮流挑战与 PNG 成绩图导出均保留。同机第二轮锁定城市、车辆、规则、配装和车流种子，双方可自行选择路线与操作。成绩和设置只保存在当前浏览器，没有账号或自动上传。

## 开发与验证

- `npm test`：规则、真实刚体、技能、车辆事件、强化 / 合约 / 每日挑战与回归测试；本轮 116 / 116 项通过。
- `npm run build`：类型检查与生产包。
- `npm run assets`：重建 **55 个 GLB**：30 个常规模型（23 车型 + 7 道具）、23 个残骸模型、2 个双挂重卡独立车头变体。
- `npm run assets:previews`：从实际三维模型重建 23 张车型缩略图。
- `npm run test:language`：中英界面、图鉴、暂停状态不重置、自然披萨预告 / 中奖、成绩和设置持久化。
- `npm run test:cities`：三城地图、城市事件、交通与建筑破坏的浏览器验证。
- `npm run test:city-ui`：城市与路线选择、四车 Q 技能、同机锁城、重开、窗口布局和成绩图导出。
- `npm run test:browser`、`npm run test:flows`、`npm run test:effects`：原参考重做阶段的模式、流程与受控效果回归脚本。
- `npm run test:performance`：生产包完整 Rush Hour 与终局的帧耗时实测。

新增三城、界面与性能脚本默认使用本机 Chrome；可通过 `CHROME_PATH` 指定浏览器，通过 `CRASH_URL` 指定试玩地址。性能脚本用 `CRASH_CITY=sf`、`sydney` 或 `london` 选择地图。最新验收范围与实测结果见 [QA-V4.md](QA-V4.md)，本轮界面、披萨和语言报告在 `artifacts/refinement-v4/`。三城版本的 [QA-V3.md](QA-V3.md)、`artifacts/city-v3/`、`artifacts/world-tour-v3/` 与 `artifacts/vehicle-v03/` 保留作为历史对照。本地数值与物理约束见 [TUNING.md](src/simulation/TUNING.md)。

原版完整关卡、车型资产、音乐配音和解锁进度未复制；精确伤害、充能、车流数量、奖金及技能数值属于本地调校。原参考阶段验收见 [QA-V2.md](QA-V2.md)，旧样机设计和验证保留在 `archive/reference-rebuild/`。
